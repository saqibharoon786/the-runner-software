# Frontend Project Structure

## Main folders
- src/app: route pages and layout files
- src/components: reusable UI and section components
- src/views: page-level view components
- src/data: content and config data
- src/lib: shared helpers and utilities
- public: static assets such as images and brand files

## Typical workflow
1. Add or update page content in src/data
2. Build UI in src/components or src/views
3. Connect routes in src/app
4. Run npm run dev for local development

## Useful commands
- npm install
- npm run dev
- npm run build
